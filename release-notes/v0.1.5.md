# 🚀 Garud AI v0.1.5 - Robotics OS & 3D Simulation Update

## 🤖 Full Robotics Operating System Simulator
This version transforms Garud AI from a control panel into a comprehensive **Robotics Operating System (ROS-like)** simulator. It provides a full-stack environment for developing, testing, and deploying autonomous robot logic.

### 🎮 3D Physics Simulation (PyBullet)
- **Live 3D View**: Real-time camera feed from the PyBullet physics engine integrated directly into the Electron UI.
- **Dynamic World**: Environment includes obstacles (walls, cubes) with real-world physics for collision testing.
- **Robot Models**: Support for standard URDF models (like R2D2) with motor and wheel physics.

### 👁️ Vision AI & Autonomous Brain
- **Llava Vision Integration**: The robot now "sees" through its camera using **Vision Language Models (VLM)** via Ollama.
- **Live Model Switching**: Dynamic selector to switch between vision models (1B, 2B, 8B, 13B) with real-time size metadata.
- **Hybrid Autonomy**: Combined decision-making using **Ultrasonic Proximity Sensors** and **AI Vision analysis** for advanced obstacle avoidance.

### 📊 Advanced Telemetry & Controls
- **High-Fidelity Dashboard**: Real-time tracking of motor RPM, battery voltage (12V simulation), CPU temperature, and WiFi signal strength.
- **Manual Overdrive**: Improved directional control grid with low-latency command execution.
- **System HUD**: Futuristic Head-Up Display overlay on the camera feed showing simulation state.

### 🐳 Hardware Deployment Guide
- **Interactive Setup**: Step-by-step visual guide for deploying the Garud AI agent to real Raspberry Pi hardware.
- **Docker & SSH Support**: Visual documentation for containerized deployment and SSH provisioning.

## 🛠️ Internal Changes
- Added `/robot/camera`, `/robot/telemetry`, `/robot/vision/models`, and `/robot/autonomy` endpoints to the FastAPI bridge.
- Created `robot_core/` layer for GPIO emulation, sensor abstraction, and vision processing.
- New React components: `SimulationView.tsx` and `RobotSetupGuide.tsx`.
- Updated `requirements.txt` with `pybullet`, `ollama`, and `opencv-python-headless`.
