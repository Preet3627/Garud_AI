# Garud AI v0.1.2 — Voice AI & Testing Mode

## 🎉 Major New Features

### 🎙️ Voice AI Assistant (Pipecat-style)
- **Hands-free voice control** — Works without holding any button
- **Custom wake word** (e.g., "Hey Jarvis", "Hello Garud") — Configurable in Settings
- **Automatic speech recognition** using browser's native SpeechRecognition API
- **Voice response via TTS** — AI speaks back using SpeechSynthesis
- **Stunning AI Orb animation** with rotating rings, scanning beam, particle bursts, and orbit dots
- **Voice waveform equalizer** — Animated bars that pulse with speech activity
- **Floating voice panel** — Shows listening/speaking status without switching tabs
- **Push-to-talk mode** (5s timeout) for quick queries

- **5 AI providers**: Ollama, OpenAI, Gemini, Claude, Custom

- **Stunning chat bubbles** with typing animation (AnimatedText) and glowing text reveal (GlowingText)
- **Per-message provider/model badge**
