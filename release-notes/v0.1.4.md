# Garud AI v0.1.4 — FastAPI & Docker Deployment

This release introduces a major architectural upgrade to the AI bridge, switching to FastAPI for better performance and adding Docker support for seamless deployment.

## 🚀 Architectural Upgrades

### ⚡ FastAPI Integration
- Replaced the legacy Python HTTP server with **FastAPI** and **Uvicorn**.
- Fully asynchronous request handling for faster Voice-to-Text (STT) and Text-to-Speech (TTS) processing.
- Added strict Pydantic model validation for API requests.
- Automatic API documentation available via `/docs` (Swagger).

### 🐳 Docker Deployment
- Added a production-ready **Dockerfile** to containerize the AI bridge.
- Simplifies deployment on any hardware (Raspberry Pi, Jetson, or Desktop) by packaging all system-level audio dependencies.
- One-command setup for the entire Python environment.

## 🛠️ Internal Improvements
- Updated `requirements.txt` with modern web dependencies (`fastapi`, `uvicorn`, `pydantic`).
- Improved error handling and traceback reporting in the voice bridge.
- Version bump to v0.1.4 across all project configurations.

## 📦 Release Assets
This release only includes essential production builds:
- Windows: `.exe`
- macOS: `.dmg`
- Linux: `.AppImage`
