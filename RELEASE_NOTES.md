# 🚀 Garud AI Robot v0.1.0 - "Dhurandhar" Edition

We are proud to present the first official release of the **Garud AI Robot** desktop application! This version transforms our advanced robot control system into a high-performance, cross-platform hub.

### ✨ Major Features
- **🖥️ Desktop Application**: Native, high-performance experience for macOS, Windows, and Linux.
- **🎙️ Pipecat Voice Integration**: Advanced full-duplex voice interaction with Voice Activity Detection (VAD).
- **🧠 Local AI (Ollama)**: Seamlessly connect to local LLMs with live model fetching and selection directly from the UI.
- **⚡ Vercel AI SDK**: Unified AI interaction layer for streaming responses and intelligent robot behavior.
- **👁️ Vision & Intelligence**: Real-time object detection (YOLOv3-tiny) and Gemini-powered scene description.
- **🎮 Multi-modal Control**: Movement via Web API, IR Remote, and several autonomous Autopilot modes.

### 🔧 What's New
- **Interactive UI**: A modern dashboard with live logs, camera streaming, and real-time AI status.
- **Automated CI/CD**: Seamless cross-platform builds and releases powered by GitHub Actions.
- **Enhanced Robot API**: Structured endpoints for movement, sensors, and AI personality control.

### 📦 Installation
Download the binary for your platform from the assets below.
- **macOS**: `.dmg` or `.zip`
- **Windows**: `.exe` (NSIS) or `.zip`
- **Linux**: `.AppImage`, `.deb`, or `.zip`
