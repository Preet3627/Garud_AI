# 🚀 Garud AI Robot v0.1.0

We are excited to announce the first official release of the **Garud AI Robot** desktop application! This version transforms our web dashboard into a powerful, cross-platform intelligence hub.

### ✨ New Features
- **🖥️ Desktop Application**: Native experience for macOS (Apple Silicon & Intel), Windows, and Linux.
- **🎙️ Pipecat Voice Integration**: Advanced full-duplex voice interaction with VAD and real-time response.
- **🧠 Local AI (Ollama)**: Connect directly to local LLMs with live model fetching and selection from the UI.
- **⚡ Vercel AI SDK**: Unified AI interaction for seamless streaming and robot intelligence.
- **👁️ Vision & Intelligence**: Real-time object detection and Gemini-powered scene description.
- **🎮 Multi-modal Control**: Movement via Web API, IR Remote, and multiple Autopilot modes.

### 🔧 Improvements
- **Automated CI/CD**: Cross-platform binaries are now automatically built and released via GitHub Actions.
- **Enhanced UI**: Modern, high-performance dashboard with live logs and camera streaming.
