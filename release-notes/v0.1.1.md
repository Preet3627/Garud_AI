# 🚀 Garud AI Robot v0.1.1 - "Auto-Pilot" Update

This version focuses on making the setup and deployment process completely seamless. You no longer need to manually copy code or configure IPs!

### ✨ New Features
- **📡 Auto-Detection**: The app now automatically finds your Garud AI Robot on the local network using mDNS (Bonjour).
- **🚀 One-Click Deploy**: Deploy the entire Python backend codebase to your Raspberry Pi directly from the desktop app.
- **⚡ Auto-Run**: The app can now remotely start and restart the robot's Python server via SSH, making manual terminal work a thing of the past.
- **🛠️ SSH Integration**: Configurable SSH credentials for secure and easy communication with your Raspbot.

### 🔧 Improvements
- **Better Connectivity**: Real-time status monitoring of the remote Python process.
- **Dependency Management**: Automated installation of Python requirements on the robot during deployment.
